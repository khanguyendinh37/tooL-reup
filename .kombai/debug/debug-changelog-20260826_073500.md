## Changes Made

### 1. Replaced resolution-dependent SRT subtitle placement
- **File:** `videodub/backend/app/core/pipeline.py`
- **Change:** Added ASS timestamp/text escaping helpers and `_write_positioned_ass_subtitles()`.
- **Why:** The previous `subtitles` filter relied on libass's default 384x288 script canvas and converted the preview's normalized top-down Y coordinate into `MarginV`. That conversion was not stable for portrait and non-16:9 videos.
- **Behavior:** The renderer now writes an ASS file with `PlayResX/PlayResY` equal to the actual video frame, scales the existing compact font style, and places every dialogue with `\\an5\\pos(video_width / 2, round(video_height * position_y))`.
- **Revert:** Replace the ASS helper/filter block with the previous `MarginV`/`subtitles` implementation and restore `ASS_PLAYRES_HEIGHT`.

### 2. Added portrait-coordinate regression coverage
- **File:** `videodub/backend/test_subtitle_roi.py`
- **Change:** Replaced the `MarginV` assertion with a video-height-independent ASS canvas/position assertion for a 720x1280 frame.
- **Why:** Prevents future changes from reintroducing the aspect-ratio-dependent positioning bug.
- **Revert:** Restore `test_margin_v_centers_text_on_the_configured_position` and its `MarginV=138` assertion.
